# Ocular

A dark/light theme pair (Rooibos/Manzanilla) built with OKLCH + APCA instead
of eyeballed hex — every contrast pair is measured, every accent hue is
optimized for maximum perceptual separation. Includes a CVD-safe (Deutan)
profile for both variants.

Full project, source palette and the other ports (kitty, ghostty, nvim, bat,
delta, tmux, and more): [github.com/Pit-CL/ocular](https://github.com/Pit-CL/ocular).

The color science behind every decision: [SCIENCE.md](https://github.com/Pit-CL/ocular/blob/main/SCIENCE.md).
