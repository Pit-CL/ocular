# Slack — tema custom Ocular

Slack acepta una cadena de 8 hex (Preferences → Themes → Custom theme, o pégala en
un mensaje y Slack ofrece "Apply Slack theme"). Orden de los campos: Column BG,
Menu Hover BG, Active Item, Active Item Text, Hover Item, Text Color,
Active Presence, Mention Badge.

## Ocular Rooibos (dark)

```
#191511,#2B2520,#D9B9FF,#15110D,#38322B,#DFD9CC,#99D694,#FFB1C4
```

## Ocular Manzanilla (light)

```
#EEE8DF,#E3DDD4,#684C9E,#F5EFE7,#D9D3C9,#3F372D,#276819,#9B393F
```

Mapeo por rol: Column BG = mantle · Menu Hover BG = surface0 · Active Item = mauve
· Active Item Text = crust (dark) / base (light) · Hover Item = surface1 · Text =
text · Active Presence = green · Mention Badge = red. Slack no soporta conmutación
automática de temas custom: pega la cadena del modo que uses.
